# 🐾 Pawfect Pet Care – Bootstrap 5 Single Page Application
### Built by: **Jacob Roland**

Pawfect Pet Care is a fully responsive single-page website built with **Bootstrap 5**, designed to showcase a fictional pet daycare, grooming, and boarding service.

This project fulfills all requirements of the **W13-P: Pawfect Pet Care** assignment, including:

- Fixed Bootstrap Navbar with smooth scrolling
- Bootstrap Carousel with 3 pet-themed slides
- Row of 3 Service Cards
- Accordion-based FAQ section
- Live hosting on the OTC student server
- GitHub repository with README and multiple commits
